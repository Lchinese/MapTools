# MapTools 后端接口文档

## 概述

MapTools 后端服务提供轨迹匹配、数据处理、文件管理等核心功能的 RESTful API 接口。本文档详细描述了所有可用的 API 端点、请求参数、响应格式和使用示例。

## 基础信息

- **基础 URL**: `http://localhost:8000`
- **API 版本**: v1
- **认证方式**: JWT Token (可选)
- **数据格式**: JSON
- **字符编码**: UTF-8
- **底图服务（前端展示）**: 天地图 WMTS `vec_w`（栅格切片，不含矢量要素）
  - 示例: `http://t0.tianditu.gov.cn/vec_w/wmts?tk=您的密钥`
- **路网数据来源（用于匹配与统计）**: OpenStreetMap 数据（Overpass/Geofabrik + osmnx/pyrosm）
- **数据来源（当前版本）**: 直接读取项目本地 `data/` 目录，不做入库
- **数据库用途（当前版本）**: 仅保留 `users` 表用于用户认证

## 测试

系统包含完整的测试套件，确保功能的稳定性和可靠性：

### 单元测试
- 覆盖核心业务逻辑和工具函数
- 包括地理工具、轨迹处理、匹配算法等模块
- 可通过 `python Tests/run_tests.py unit` 运行

### 集成测试

### 运行所有测试
- 运行所有测试: `python Tests/run_tests.py all`
- 支持 pytest 和 unittest 两种测试框架

## 2. 轨迹管理接口

### 2.1 上传轨迹文件

**POST** `/api/v1/trajectories/upload`

上传轨迹文件（支持多种格式：GPX、KML、CSV、TXT）。

#### 请求参数
- **Content-Type**: `multipart/form-data`
- **file**: 轨迹文件（必需）
- **name**: 轨迹名称（可选）
- **description**: 轨迹描述（可选）
- **data_type**: 数据类型（可选，auto/taxi_gps/bus_card/metro_card/taxi_transaction/bus_gps/gpx/csv）

#### 支持的文件格式
- **GPX**: 标准GPS交换格式
- **CSV**: 逗号分隔值格式
- **TXT**: 文本格式（出租车GPS数据）
- **KML**: Google Earth格式

#### 数据格式说明
- **出租车GPS**: `日期,时间,类型,车牌号,经度,纬度,速度,方向,状态,未知` (连续轨迹)
- **公交刷卡**: `卡号 上车时间 对应线路 刷卡费用 终端号 车牌号` (起始终止站点)
- **地铁刷卡**: `卡号,站点,时间,交易类型,刷卡费用` (起始终止站点)
- **出租车交易**: `车牌号,日期,上车时间,下车时间,单价*100,营业里程*1000,计时时间,金额*100,空驶里程*1000,出租车车型,所属公司` (起始终止时间)

#### 响应示例
```json
{
  "success": true,
  "data": {
    "trajectory_id": "traj_123456",
    "filename": "example.gpx",
    "file_size": 1024,
    "point_count": 150,
    "upload_time": "2025-09-16T18:16:00Z",
    "status": "uploaded"
  },
  "message": "文件上传成功"
}
```

## 3. 地图匹配接口

### 3.1 开始地图匹配

**POST** `/api/v1/matching/start`

开始对轨迹进行地图匹配。

#### 请求体
```json
{
  "trajectory_id": "traj_123456",
  "algorithm": "hmm",
  "parameters": {
    "sigma": 4.07,
    "beta": 0.0096,
    "max_dist": 200
  },
  "road_network": "osm_default"
}
```

#### 参数说明
- `trajectory_id`: 轨迹ID（必需）
- `algorithm`: 匹配算法（hmm, greedy）
- `parameters`: 算法参数
- `road_network`: 路网数据源（如 osm_default，表示基于 OSM 的默认路网）

#### 响应示例
```json
{
  "success": true,
  "data": {
    "task_id": "task_789012",
    "trajectory_id": "traj_123456",
    "algorithm": "hmm",
    "status": "queued",
    "estimated_time": 30,
    "created_at": "2025-09-16T00:00:00Z"
  },
  "message": "匹配任务已创建"
}
```

### 3.2 查询匹配状态

**GET** `/api/v1/matching/status/{task_id}`

查询地图匹配任务的状态。

#### 路径参数
- `task_id`: 任务ID

#### 响应示例
```json
{

  "data": {
    "task_id": "task_789012",
    "status": "completed",
    "progress": 100,
    "result": {
```

**GET** `/api/v1/matching/download/{task_id}`

下载匹配结果为文件。

#### 路径参数

#### 查询参数
- `format`: 文件格式（gpx, kml, csv, geojson）

#### 响应
返回文件流，Content-Type 根据格式设置。

## 4. 路网管理接口

### 4.1 获取路网信息

**GET** `/api/v1/roadnetworks`

获取可用的路网数据源。

#### 路网与底图配置
- 底图：天地图 `vec_w` WMTS（前端可视化展示）。
- 路网：从 OSM 数据构建（Overpass/Geofabrik + osmnx/pyrosm 解析），用于匹配与统计。

#### 响应示例
```json
{
  "success": true,
  "data": {
    "networks": [
      {
        "network_id": "osm_default",
        "name": "OSM 默认路网",
        "description": "基于 OpenStreetMap 的路网数据",
        "coverage": {
          "bounds": {
            "min_lat": 39.0,
            "max_lat": 41.0,
            "min_lng": 115.0,
            "max_lng": 118.0
          },
          "area": "北京市"
        },
        "statistics": {
          "total_roads": 50000,
          "total_length": 15000.5
        },
        "last_updated": "2025-09-16T00:00:00Z"
      }
    ]
  }
}
```

### 4.2 获取路网统计

**GET** `/api/v1/roadnetworks/{network_id}/stats`

获取指定路网的统计信息。

#### 统计说明
- 路网几何与长度计算基于 OSM 数据（WGS84 或投影坐标系，视构建方式选择）。
- 底图 WMTS 仅作可视化展示，不提供矢量要素查询。

#### 路径参数
- `network_id`: 路网ID

#### 响应示例
```json
{
  "success": true,
  "data": {
    "network_id": "osm_default",
    "statistics": {
      "total_roads": 50000,
      "total_length": 15000.5,
      "road_types": {
        "highway": 25000,
        "primary": 15000,
        "secondary": 10000
      },
      "coverage_area": 16410.54
    },
    "last_updated": "2025-09-16T00:00:00Z"
  }
}
```

## 6. 起始终止数据管理接口

### 6.1 获取起始终止记录

**GET** `/api/v1/origin-destination/records`

获取起始终止记录列表。

#### 查询参数
- `page`: 页码（默认：1）
- `limit`: 每页数量（默认：20，最大：100）
- `record_type`: 记录类型（bus_card, metro_card, taxi_transaction）
- `status`: 配对状态（paired, unpaired, processed）
- `start_date`: 开始日期（ISO 格式）
- `end_date`: 结束日期（ISO 格式）

#### 响应示例
```json
{
  "success": true,
  "data": {
    "records": [
      {
        "record_id": "od_123456",
        "trajectory_id": "traj_123456",
        "record_type": "bus_card",
        "passenger_id": "291403498",
        "origin_station": "东湖客运站",
        "destination_station": "世界之窗",
        "origin_time": "2025-09-16T07:00:51Z",
        "destination_time": "2025-09-16T07:30:15Z",
        "line_id": "605路31",
        "vehicle_id": "粤B72366",
        "fare": 200,
        "distance": 15000,
        "duration": 1764,
        "status": "paired"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 20,
      "total": 1,
      "pages": 1
    }
  }
}
```

### 6.2 配对起始终止记录

**POST** `/api/v1/origin-destination/pair`

配对起始终止记录（进出站配对）。

#### 请求体
```json
{
  "record_type": "metro_card",
  "pairing_criteria": {
    "time_window": 3600,
    "max_distance": 1000
  }
}
```

#### 响应示例
```json
{
  "success": true,
  "data": {
    "paired_count": 150,
    "unpaired_count": 25,
    "pairing_results": [
      {
        "record_id": "od_123456",
        "status": "paired",
        "confidence": 0.95
      }
    ]
  },
  "message": "配对完成"
}
```

## 7. 许可与署名
- OpenStreetMap 数据遵循 ODbL 许可，需要保留署名：© OpenStreetMap contributors。
- 天地图 WMTS 使用需遵守其服务条款与密钥配额；WMTS 为栅格切片，不能直接获取矢量要素。
