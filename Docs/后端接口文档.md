# MapTools 后端接口文档

## 概述

MapTools 后端服务提供轨迹匹配、数据处理、文件管理等核心功能的 RESTful API 接口。本文档详细描述了所有可用的 API 端点、请求参数、响应格式和使用示例。

## 基础信息

- **基础 URL**: `http://localhost:8000`
- **API 版本**: v1
- **认证方式**: JWT Token (可选)
- **数据格式**: JSON
- **字符编码**: UTF-8
- **地图服务**: 天地图API (Tianditu)
  - 经纬度投影: `http://t0.tianditu.gov.cn/vec_c/wmts?tk=您的密钥` (面积和距离测定)
  - 球面墨卡托投影: `http://t0.tianditu.gov.cn/vec_w/wmts?tk=您的密钥` (前端展示)
- **轨迹数据**: 直接从本地文件系统读取出租车轨迹数据

## 测试

系统包含完整的测试套件，确保功能的稳定性和可靠性：

### 单元测试
- 覆盖核心业务逻辑和工具函数
- 包括地理工具、轨迹处理、匹配算法等模块
- 可通过 `python Tests/run_tests.py unit` 运行

### 集成测试
- 验证 API 端点功能

- 可通过 `python Tests/run_tests.py integration` 运行

### 运行所有测试

## 2. 轨迹管理接口

### 2.1 上传轨迹文件

**POST** `/api/v1/trajectories/upload`

上传轨迹文件（支持多种格式：GPX、KML、CSV、TXT）。

#### 请求参数
- **Content-Type**: `multipart/form-data`
- **file**: 轨迹文件（必需）
- **name**: 轨迹名称（可选）
- **description**: 轨迹描述（可选）
- **data_type**: 数据类型（可选，auto/taxi_gps/bus_card/metro_card/taxi_transaction/bus_gps/gpx/csv）

#### 支持的文件格式
- **GPX**: 标准GPS交换格式
- **CSV**: 逗号分隔值格式
- **TXT**: 文本格式（出租车GPS数据）
- **KML**: Google Earth格式

#### 数据格式说明
- **出租车GPS**: `日期,时间,类型,车牌号,经度,纬度,速度,方向,状态,未知` (连续轨迹)
- **公交刷卡**: `卡号 上车时间 对应线路 刷卡费用 终端号 车牌号` (起始终止站点)
- **地铁刷卡**: `卡号,站点,时间,交易类型,刷卡费用` (起始终止站点)
- **出租车交易**: `车牌号,日期,上车时间,下车时间,单价*100,营业里程*1000,计时时间,金额*100,空驶里程*1000,出租车车型,所属公司` (起始终止时间)
- **公交GPS**: `系统时间,类型,终端号,车牌号,线路id,子线路id,公司,状态,经度,纬度,高度,gps上报时间,定位速度,方向,行车记录仪速度,里程,未知,未知,未知` (连续轨迹)

#### 响应示例
```json
{
  "success": true,
  "data": {
    "trajectory_id": "traj_123456",
    "filename": "example.gpx",
    "file_size": 1024,
    "point_count": 150,
    "upload_time": "2025-09-16T18:16:00Z",
    "status": "uploaded"
  },
  "message": "文件上传成功"
}
```

## 4. 路网管理接口

### 4.1 获取路网信息

**GET** `/api/v1/roadnetworks`

获取可用的路网数据源。

#### 地图服务配置

系统使用天地图API作为地图服务提供商，支持两种投影方式：

- **经纬度投影 (WGS84)**: `http://t0.tianditu.gov.cn/vec_c/wmts?tk=您的密钥`
  - 用途：地图各个区域面积和距离测定
  - 坐标系：EPSG:4326
  - 适用场景：精确的地理计算和测量

- **球面墨卡托投影 (Web Mercator)**: `http://t0.tianditu.gov.cn/vec_w/wmts?tk=您的密钥`
  - 用途：地图的前端展示
  - 坐标系：EPSG:3857
  - 适用场景：Web地图显示和交互

#### 天地图API密钥配置

在使用地图服务前，需要配置天地图API密钥：

```json
{
  "map_config": {
    "tianditu_api_key": "your_tianditu_api_key",
    "projections": {
      "wgs84": {
        "url": "http://t0.tianditu.gov.cn/vec_c/wmts",
        "description": "经纬度投影，用于面积和距离测定"
      },
      "web_mercator": {
        "url": "http://t0.tianditu.gov.cn/vec_w/wmts", 
        "description": "球面墨卡托投影，用于前端展示"
      }
    }
  }
}
```

#### 响应示例
```json
{
  "success": true,
  "data": {
    "networks": [
      {
        "network_id": "default",
        "name": "默认路网",
        "description": "基于 OpenStreetMap 的路网数据",
        "coverage": {
          "bounds": {
            "min_lat": 39.0,
            "max_lat": 41.0,
            "min_lng": 115.0,
            "max_lng": 118.0
          },
          "area": "北京市"
        },
        "statistics": {
          "total_roads": 50000,
          "total_length": 15000.5
        },
        "last_updated": "2025-09-16T00:00:00Z"
      }
    ]
  }
}
```

## 8. 使用示例

### 8.1 完整工作流程示例

```
# 1. 上传轨迹文件
curl -X POST "http://localhost:8000/api/v1/trajectories/upload" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@example.gpx" \
  -F "name=测试轨迹"

# 2. 开始地图匹配
curl -X POST "http://localhost:8000/api/v1/matching/start" \
  -H "Content-Type: application/json" \
  -d '{
    "trajectory_id": "traj_123456",
    "algorithm": "hmm",
    "parameters": {
      "sigma": 4.07,
      "beta": 0.0096
    }
  }'

# 3. 查询匹配状态
curl "http://localhost:8000/api/v1/matching/status/task_789012"

# 4. 获取匹配结果
curl "http://localhost:8000/api/v1/matching/result/task_789012"

# 5. 下载结果文件
curl "http://localhost:8000/api/v1/matching/download/task_789012?format=gpx" \
  -o matched_result.gpx
```

    url = f"{BASE_URL}/api/v1/trajectories/upload"
    files = {"file": open(file_path, "rb")}
    data = {"name": name} if name else {}
    
    response = requests.post(url, files=files, data=data)
    return response.json()

# 开始匹配
def start_matching(trajectory_id, algorithm="hmm"):
    url = f"{BASE_URL}/api/v1/matching/start"
    data = {
        "trajectory_id": trajectory_id,
        "algorithm": algorithm,
        "parameters": {"sigma": 4.07, "beta": 0.0096}
    }
    
    response = requests.post(url, headers=headers, json=data)
    return response.json()

# 查询状态
def get_task_status(task_id):
    url = f"{BASE_URL}/api/v1/matching/status/{task_id}"
    response = requests.get(url)
    return response.json()

# 使用示例
if __name__ == "__main__":
    # 上传轨迹

    # 等待完成并获取结果

## 10. 天地图API配置

4. 在系统配置中设置密钥

### 10.2 投影方式说明

#### 经纬度投影 (WGS84)
- **服务地址**: `http://t0.tianditu.gov.cn/vec_c/wmts?tk=您的密钥`
- **坐标系**: EPSG:4326
- **用途**: 
  - 地图各个区域面积和距离测定
  - 精确的地理计算
  - 轨迹匹配算法计算
- **特点**: 保持真实的地理坐标，适合精确测量

#### 球面墨卡托投影 (Web Mercator)
- **服务地址**: `http://t0.tianditu.gov.cn/vec_w/wmts?tk=您的密钥`
- **坐标系**: EPSG:3857
- **用途**:
  - 地图的前端展示
  - Web地图交互
  - 用户界面显示
- **特点**: 适合Web显示，保持形状不变形
