# MapTools 数据库设计文档

## 概述

本文档描述当前版本数据库设计：系统采用**MongoDB数据库**存储轨迹数据、路网数据、行政区划数据和路径数据，支持地理空间查询和实时轨迹匹配。MySQL仅用于用户认证（`users` 表）。

## 数据库配置

### 主数据库：MongoDB
- **类型**: MongoDB 4.4+
- **用途**: 存储轨迹数据、路网数据、行政区划数据、路径数据
- **连接**: 通过 `pymongo` 驱动连接
- **地理空间支持**: 支持2dsphere索引，用于地理空间查询

### 认证数据库：MySQL
- **类型**: MySQL 8.0（现有环境）
- **字符集**: utf8mb4；**排序规则**: utf8mb4_unicode_ci；**引擎**: InnoDB
- **用途**: 仅用于用户认证和权限管理
- **测试环境**: 可使用 SQLite 以运行集成测试

## MongoDB集合设计

### 1. GPS轨迹点集合 (gps_points)
```javascript
{
    "_id": ObjectId,
    "vehicle_id": String,           // 车牌号
    "lng": Number,                  // 经度
    "lat": Number,                  // 纬度
    "timestamp": Date,              // 时间戳
    "speed": Number,                // 速度 (km/h)
    "direction": Number,            // 方向角
    "accuracy": Number,             // 精度
    "created_at": Date,             // 创建时间
    "updated_at": Date              // 更新时间
}
```

**索引设计**:
```javascript
// 地理空间索引
db.gps_points.createIndex({ "lng": 1, "lat": 1 }, { "2dsphere": true })

// 车牌号索引
db.gps_points.createIndex({ "vehicle_id": 1 })

// 时间索引
db.gps_points.createIndex({ "timestamp": 1 })

// 复合索引
db.gps_points.createIndex({ "vehicle_id": 1, "timestamp": 1 })
```

### 2. 原始轨迹集合 (original_trajectories)
```javascript
{
    "_id": ObjectId,
    "trajectory_id": String,        // 轨迹唯一标识
    "vehicle_id": String,           // 车牌号
    "start_time": Date,             // 开始时间
    "end_time": Date,               // 结束时间
    "point_count": Number,          // 轨迹点数量
    "total_distance": Number,       // 总距离 (米)
    "file_name": String,            // 原始文件名
    "created_at": Date,             // 创建时间
    "updated_at": Date              // 更新时间
}
```

**索引设计**:
```javascript
db.original_trajectories.createIndex({ "vehicle_id": 1 })
db.original_trajectories.createIndex({ "start_time": 1, "end_time": 1 })
```

### 3. 路网数据集合 (road_network)
```javascript
{
    "_id": ObjectId,
    "road_id": String,              // 道路唯一标识
    "name": String,                 // 道路名称
    "road_type": String,            // 道路类型
    "geometry": {                   // 道路几何数据
        "type": "LineString",
        "coordinates": [[lng, lat], ...]
    },
    "properties": {                 // 道路属性
        "max_speed": Number,
        "lanes": Number,
        "surface": String
    },
    "created_at": Date,             // 创建时间
    "updated_at": Date              // 更新时间
}
```

**索引设计**:
```javascript
// 地理空间索引
db.road_network.createIndex({ "geometry": "2dsphere" })

// 道路类型索引
db.road_network.createIndex({ "road_type": 1 })

// 道路名称索引
db.road_network.createIndex({ "name": 1 })
```

### 4. 行政区划集合 (administrative_areas)
```javascript
{
    "_id": ObjectId,
    "gb_code": String,              // 国标编码
    "name": String,                 // 行政区划名称
    "level": Number,                // 行政区划级别
    "boundary": {                   // 边界几何数据
        "type": "MultiPolygon",
        "coordinates": [[[lng, lat], ...]]
    },
    "center": {                     // 中心点坐标
        "lng": Number,
        "lat": Number
    },
    "created_at": Date,             // 创建时间
    "updated_at": Date              // 更新时间
}
```

**索引设计**:
```javascript
// 地理空间索引
db.administrative_areas.createIndex({ "boundary": "2dsphere" })

// 国标编码索引
db.administrative_areas.createIndex({ "gb_code": 1 })

// 级别索引
db.administrative_areas.createIndex({ "level": 1 })
```

### 5. 轨迹路径集合 (trajectory_paths)
```javascript
{
    "_id": ObjectId,
    "path_id": String,              // 路径唯一标识 (MD5哈希)
    "start_point": {                // 起点信息
        "lng": Number,
        "lat": Number,
        "timestamp": Date
    },
    "end_point": {                  // 终点信息
        "lng": Number,
        "lat": Number,
        "timestamp": Date
    },
    "path_coordinates": [[Number, Number]], // 路径坐标序列
    "distance": Number,             // 路径距离 (米)
    "duration": Number,             // 预计时间 (秒)
    "route_info": {                 // 详细路径信息
        "street_names": [String],
        "toll_status": Number,
        "turn_instructions": [String]
    },
    "created_at": Date,             // 创建时间
    "updated_at": Date,             // 更新时间
    "usage_count": Number           // 使用次数统计
}
```

**索引设计**:
```javascript
// 路径ID索引
db.trajectory_paths.createIndex({ "path_id": 1 })

// 起点终点索引
db.trajectory_paths.createIndex({ "start_point.lng": 1, "start_point.lat": 1 })
db.trajectory_paths.createIndex({ "end_point.lng": 1, "end_point.lat": 1 })

// 使用次数索引
db.trajectory_paths.createIndex({ "usage_count": -1 })
```

## MySQL表结构设计

### 1. 用户表 (users)
```sql
CREATE TABLE users (
    user_id VARCHAR(36) PRIMARY KEY COMMENT '用户ID',
    username VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
    email VARCHAR(100) NOT NULL UNIQUE COMMENT '邮箱',
    password_hash VARCHAR(255) NOT NULL COMMENT '密码哈希',
    full_name VARCHAR(100) COMMENT '全名',
    phone VARCHAR(20) COMMENT '手机号',
    avatar_url VARCHAR(500) COMMENT '头像URL',
    is_active BOOLEAN DEFAULT TRUE COMMENT '是否激活',
    is_admin BOOLEAN DEFAULT FALSE COMMENT '是否管理员',
    last_login_at TIMESTAMP NULL COMMENT '最后登录时间',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_username (username),
    INDEX idx_email (email),
    INDEX idx_created_at (created_at)
) ENGINE=InnoDB COMMENT='用户表';
```

## 数据存储策略

### MongoDB数据
- **轨迹数据**: 存储在MongoDB的`gps_points`集合，支持按车牌号分页查询
- **原始轨迹**: 存储在`original_trajectories`集合，包含轨迹元数据
- **路网数据**: 存储在`road_network`集合，从天地图WFS服务获取并持久化
- **行政区划数据**: 存储在`administrative_areas`集合，从天地图行政区划API获取边界轮廓
- **路径数据**: 存储在`trajectory_paths`集合，从天地图驾车规划API获取真实路径

### MySQL数据
- **用户认证**: 仅存储用户认证和权限管理相关数据

### 本地文件数据
- **用户上传文件**: 存储在`UserUploads/`目录，支持GPS原始点文件
- **配置文件**: 存储在`BackendService/.env`，包含API密钥等敏感信息

## 性能优化

### MongoDB优化
- **地理空间索引**: 为所有地理坐标字段建立2dsphere索引
- **复合索引**: 为常用查询组合建立复合索引
- **分片策略**: 按车牌号分片，提高查询性能
- **数据压缩**: 启用MongoDB数据压缩，减少存储空间

### 查询优化
- **分页查询**: 使用MongoDB的skip和limit实现分页
- **地理空间查询**: 使用$geoWithin和$near操作符优化地理查询
- **聚合管道**: 使用MongoDB聚合管道优化复杂查询

## 备份与安全

### MongoDB备份
- **全量备份**: 定期备份所有集合数据
- **增量备份**: 使用oplog进行增量备份
- **地理数据备份**: 特别关注地理空间数据的完整性

### MySQL备份
- **用户数据备份**: 定期备份users表数据
- **配置备份**: 备份.env文件和密钥配置

### 安全措施
- **访问控制**: 配置MongoDB和MySQL的访问权限
- **数据加密**: 敏感数据加密存储
- **审计日志**: 记录所有数据操作日志
