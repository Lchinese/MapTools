# 日志系统设计

## 概述

日志系统是 MapTools 项目的重要组成部分，用于记录系统运行状态、用户操作行为以及错误异常信息，帮助开发人员快速定位问题并进行系统优化。

## 功能特性

1. 多级别日志记录 (DEBUG/INFO/WARNING/ERROR/CRITICAL)
2. 结构化日志格式，便于后续分析处理
3. 日志轮转功能，避免单个日志文件过大
4. 控制台和文件双重输出
5. 异常堆栈信息完整记录
6. 性能影响最小化

## 日志级别说明

- **DEBUG**: 详细的调试信息，通常只在诊断问题时使用
- **INFO**: 确认程序按预期工作的一般信息
- **WARNING**: 表示发生了意外情况，但程序仍能正常工作
- **ERROR**: 由于严重问题，程序的某些功能无法执行
- **CRITICAL**: 严重错误，程序可能无法继续运行

## 日志格式

日志采用统一的格式，包含以下信息：
```
[时间戳] [日志级别] [模块名] [函数名:行号] - 日志消息
```

## 日志轮转策略

- 按时间轮转：每天生成一个新的日志文件
- 按大小轮转：单个日志文件超过 10MB 时进行轮转
- 保留最近 30 天的日志文件

## 集成方案

日志系统将集成到整个后端服务中，各个模块都可以通过统一的接口进行日志记录。
