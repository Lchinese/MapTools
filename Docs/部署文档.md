# MapTools 部署文档

## 概述

本文档详细描述了 MapTools 系统的部署流程，包括环境准备、服务配置、容器化部署和监控设置。支持开发环境、测试环境和生产环境的部署。

## 部署架构

### 系统架构图

```
┌─────────────────┐    ┌─────────────────┐
│   Frontend      │    │   Backend       │
│   (React)       │◄──►│   (FastAPI)     │
│   Port: 3000    │    │   Port: 8000    │
└─────────────────┘    └─────────────────┘
                                │
        ┌───────────────────────┼───────────────────────┐
        │                       │                       │
        ▼                       ▼                       ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Redis         │    │   Celery        │    │ 本地轨迹数据文件 │
│   Port: 6379    │◄──►│   Workers       │    │   (data目录)     │
└─────────────────┘    └─────────────────┘    └─────────────────┘
        │
        ▼
┌─────────────────┐
│   Flower        │
│   Port: 5555    │
└─────────────────┘
```

### 服务组件

| 组件 | 描述 | 端口 | 依赖 |
|------|------|------|------|
| Frontend | React 前端应用 | 3000 | Backend API |
| Backend | FastAPI 后端服务 | 8000 | Redis |
| Redis | 缓存和消息队列 | 6379 | - |
| Celery Worker | 异步任务处理 | - | Redis |
| Celery Beat | 定时任务调度 | - | Redis |
| Flower | Celery 监控界面 | 5555 | Redis |
| 本地轨迹数据 | 出租车轨迹数据文件 | - | - |

### 测试环境
- 开发和测试可使用 SQLite 数据库以简化配置（仅用于用户认证）
- 提供专门的测试脚本运行测试套件
- 支持在部署前运行测试以验证系统功能

## 环境要求

### 系统要求

- **操作系统**: Linux (Ubuntu 20.04+), macOS, Windows 10+
- **内存**: 最小 4GB，推荐 8GB+
- **存储**: 最小 20GB 可用空间

### 开发环境依赖

- Python 3.8+
- Node.js 14+
- Redis 6.0+
- Git

### Python 依赖包
项目依赖通过 `requirements.txt` 管理，主要包含：
- fastapi - Web 框架
- celery - 异步任务处理
- pytest - 测试框架

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/maptools/maptools.git
cd maptools
```

### 2. 环境配置

```bash
# 复制环境配置文件
cp env.example .env

# 编辑环境变量
nano .env
```

### 3. 启动服务

```bash
# 启动所有服务
docker-compose up -d

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f
```

### 4. 访问应用

- **前端应用**: http://localhost:3000
- **后端 API**: http://localhost:8000
- **API 文档**: http://localhost:8000/docs
- **Celery 监控**: http://localhost:5555

## 详细部署步骤

### 1. 环境准备

#### 1.1 安装 Docker

**Ubuntu/Debian:**
```bash
# 更新包索引
sudo apt-get update

# 安装依赖
sudo apt-get install apt-transport-https ca-certificates curl gnupg lsb-release

# 添加 Docker 官方 GPG 密钥
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg

# 添加 Docker 仓库
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装 Docker
sudo apt-get update
sudo apt-get install docker-ce docker-ce-cli containerd.io

# 安装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/download/v2.20.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
```

#### 1.2 Docker Compose 生产配置

创建 `docker-compose.prod.yml`：

```yaml
version: '3.8'

services:
  # 数据库
  db:
    image: mysql:8.0
    container_name: maptools_mysql_prod
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE}
      MYSQL_USER: ${MYSQL_USER}
      MYSQL_PASSWORD: ${MYSQL_PASSWORD}
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql
      - ./BackendService/scripts/init.sql:/docker-entrypoint-initdb.d/init.sql
    networks:
      - maptools_network
    restart: unless-stopped
    deploy:
      resources:
        limits:
          memory: 2G
        reservations:
          memory: 1G

  # Redis
  redis:
    image: redis:7-alpine
    container_name: maptools_redis_prod
    command: redis-server --requirepass ${REDIS_PASSWORD}
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    networks:
      - maptools_network
    restart: unless-stopped
    deploy:
      resources:
        limits:
          memory: 512M
        reservations:
          memory: 256M

  # 后端服务
  backend:
    build:
      context: ./BackendService
      dockerfile: dockerfile
    container_name: maptools_backend_prod
    environment:
      - DATABASE_URL=${DATABASE_URL}
      - REDIS_URL=${REDIS_URL}
      - CELERY_BROKER_URL=${CELERY_BROKER_URL}
      - CELERY_RESULT_BACKEND=${CELERY_RESULT_BACKEND}
      - SECRET_KEY=${SECRET_KEY}
      - JWT_SECRET_KEY=${JWT_SECRET_KEY}
    ports:
      - "8000:8000"
    volumes:
      - ./BackendService:/app
      - user_uploads:/app/user_uploads
      - external_data:/app/external_data
      - logs:/app/logs
    depends_on:
      - db
      - redis
    networks:
      - maptools_network
    restart: unless-stopped
    deploy:
      replicas: 2
      resources:
        limits:
          memory: 1G
        reservations:
          memory: 512M

  # Celery Worker
  celery_worker:
    build:
      context: ./BackendService
      dockerfile: dockerfile
    container_name: maptools_celery_worker_prod
    command: ["uv", "run", "celery", "-A", "AsyncTasks.celery_app", "worker", "--loglevel=info", "--concurrency=4"]
    environment:
      - DATABASE_URL=${DATABASE_URL}
      - REDIS_URL=${REDIS_URL}
      - CELERY_BROKER_URL=${CELERY_BROKER_URL}
      - CELERY_RESULT_BACKEND=${CELERY_RESULT_BACKEND}
    volumes:
      - ./BackendService:/app
      - user_uploads:/app/user_uploads
      - external_data:/app/external_data
      - logs:/app/logs
    depends_on:
      - db
      - redis
    networks:
      - maptools_network
    restart: unless-stopped
    deploy:
      replicas: 3
      resources:
        limits:
          memory: 1G
        reservations:
          memory: 512M

  # Nginx 反向代理
  nginx:
    image: nginx:alpine
    container_name: maptools_nginx_prod
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/nginx.conf
      - ./nginx/ssl:/etc/nginx/ssl
      - user_uploads:/var/www/uploads
    depends_on:
      - backend
    networks:
      - maptools_network
    restart: unless-stopped

volumes:
  mysql_data:
  redis_data:
  user_uploads:
  external_data:
  logs:

networks:
  maptools_network:
    driver: bridge
```

### 2. Nginx 配置

创建 `nginx/nginx.conf`：

```nginx
events {
    worker_connections 1024;
}

http {
    upstream backend {
        server backend:8000;
    }

    server {
        listen 80;
        server_name your-domain.com;
        
        # 重定向到 HTTPS
        return 301 https://$server_name$request_uri;
    }

    server {
        listen 443 ssl http2;
        server_name your-domain.com;

        # SSL 配置
        ssl_certificate /etc/nginx/ssl/cert.pem;
        ssl_certificate_key /etc/nginx/ssl/key.pem;
        ssl_protocols TLSv1.2 TLSv1.3;
        ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512:ECDHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES256-GCM-SHA384;
        ssl_prefer_server_ciphers off;

        # 安全头
        add_header X-Frame-Options DENY;
        add_header X-Content-Type-Options nosniff;
        add_header X-XSS-Protection "1; mode=block";
        add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;

        # 文件上传大小限制
        client_max_body_size 50M;

        # API 代理
        location /api/ {
            proxy_pass http://backend;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            
            # 超时设置
            proxy_connect_timeout 60s;
            proxy_send_timeout 60s;
            proxy_read_timeout 60s;
        }

        # 静态文件
        location /uploads/ {
            alias /var/www/uploads/;
            expires 1y;
            add_header Cache-Control "public, immutable";
        }

        # 健康检查
        location /health {
            proxy_pass http://backend;
            access_log off;
        }
    }
}
```

### 3. 部署脚本

创建 `deploy.sh`：

```bash
#!/bin/bash

set -e

# 颜色定义
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
NC='\033[0m' # No Color

# 日志函数
log_info() {
    echo -e "${GREEN}[INFO]${NC} $1"
}

log_warn() {
    echo -e "${YELLOW}[WARN]${NC} $1"
}

log_error() {
    echo -e "${RED}[ERROR]${NC} $1"
}

# 检查环境
check_environment() {
    log_info "检查部署环境..."
    
    # 检查 Docker
    if ! command -v docker &> /dev/null; then
        log_error "Docker 未安装"
        exit 1
    fi
    
    # 检查 Docker Compose
    if ! command -v docker-compose &> /dev/null; then
        log_error "Docker Compose 未安装"
        exit 1
    fi
    
    # 检查环境文件
    if [ ! -f ".env" ]; then
        log_error "环境配置文件 .env 不存在"
        exit 1
    fi
    
    log_info "环境检查通过"
}

# 备份数据
backup_data() {
    log_info "备份现有数据..."
    
    BACKUP_DIR="backups/$(date +%Y%m%d_%H%M%S)"
    mkdir -p "$BACKUP_DIR"
    
    # 备份数据库
    if docker-compose ps db | grep -q "Up"; then
        docker-compose exec -T db mysqldump -u root -p"$MYSQL_ROOT_PASSWORD" maptools > "$BACKUP_DIR/database.sql"
        log_info "数据库备份完成: $BACKUP_DIR/database.sql"
    fi
    
    # 备份上传文件
    if [ -d "user_uploads" ]; then
        cp -r user_uploads "$BACKUP_DIR/"
        log_info "文件备份完成: $BACKUP_DIR/user_uploads"
    fi
}

# 停止服务
stop_services() {
    log_info "停止现有服务..."
    docker-compose down
}

# 更新代码
update_code() {
    log_info "更新代码..."
    git pull origin main
}

# 构建镜像
build_images() {
    log_info "构建 Docker 镜像..."
    docker-compose build --no-cache
}

# 启动服务
start_services() {
    log_info "启动服务..."
    docker-compose up -d
    
    # 等待服务启动
    log_info "等待服务启动..."
    sleep 30
    
    # 检查服务状态
    if docker-compose ps | grep -q "Up"; then
        log_info "服务启动成功"
    else
        log_error "服务启动失败"
        docker-compose logs
        exit 1
    fi
}

# 运行数据库迁移
run_migrations() {
    log_info "运行数据库迁移..."
    docker-compose exec backend python -m alembic upgrade head
}

# 健康检查
health_check() {
    log_info "执行健康检查..."
    
    # 检查后端服务
    if curl -f http://localhost:8000/health > /dev/null 2>&1; then
        log_info "后端服务健康检查通过"
    else
        log_error "后端服务健康检查失败"
        exit 1
    fi
    
    # 检查数据库
    if docker-compose exec -T db mysql -u root -p"$MYSQL_ROOT_PASSWORD" -e "SELECT 1" > /dev/null 2>&1; then
        log_info "数据库健康检查通过"
    else
        log_error "数据库健康检查失败"
        exit 1
    fi
}

# 清理旧镜像
cleanup_images() {
    log_info "清理未使用的 Docker 镜像..."
    docker image prune -f
}

# 主函数
main() {
    log_info "开始部署 MapTools..."
    
    check_environment
    backup_data
    stop_services
    update_code
    build_images
    start_services
    run_migrations
    health_check
    cleanup_images
    
    log_info "部署完成！"
    log_info "访问地址: http://localhost:8000"
    log_info "API 文档: http://localhost:8000/docs"
}

# 执行主函数
main "$@"
```

# 创建备份脚本

#!/bin/bash
