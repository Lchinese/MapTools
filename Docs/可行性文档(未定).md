## 一、系统概述

本系统旨在实现将 GPS 轨迹点序列智能匹配到道路网络上的功能，支持沿路网路径连接轨迹点，提供真实的路网轨迹展示。系统采用MongoDB数据库存储，支持分页查询和实时路网匹配。

### 核心功能（当前版本）
- ✅ 基于MongoDB数据库存储轨迹数据（`gps_points`、`original_trajectories`、`road_network`）
- ✅ 支持分页查询车辆轨迹数据（按车牌号分页）
- ✅ 路网数据：天地图 WFS 服务 + MongoDB持久化存储
- ✅ 轨迹匹配：GPS点吸附到最近道路节点
- ✅ 沿路网路径连接：同车牌时序相邻点间沿路网最短路径连接
- ✅ 前端展示：React + Leaflet，支持原始轨迹与匹配轨迹切换
- ✅ 实时数据加载：从数据库动态加载轨迹数据
- ✅ 使用 `uv` 管理 Python 依赖
- ✅ 完整的日志记录系统

## 四、数据与存储策略（当前版本）
- **轨迹数据**：存储在MongoDB的`gps_points`集合，支持按车牌号分页查询
- **原始轨迹**：存储在`original_trajectories`集合，包含轨迹点序列和元数据
- **路网数据**：存储在`road_network`集合，从天地图WFS服务获取并持久化
- **匹配结果**：实时计算GPS点与路网的最短距离匹配
- **路径连接**：同车牌时序相邻点间沿路网最短路径连接

## 五、沿路网路径连接算法

### 5.1 核心思路
同车牌时序相邻的两个GPS点不再用直线连接，而是：
1. 将GPS点匹配到最近的路网节点
2. 在路网图中计算两点间的最短路径
3. 沿最短路径绘制轨迹线

### 5.2 技术实现

#### 步骤1：路网图构建
```python
import networkx as nx
from shapely.geometry import Point, LineString

def build_road_network_graph(road_data):
    """构建路网图"""
    G = nx.Graph()
    
    for road in road_data:
        # 提取道路节点
        nodes = extract_road_nodes(road['geometry'])
        # 添加节点和边
        for i in range(len(nodes) - 1):
            G.add_edge(nodes[i], nodes[i+1], 
                      weight=calculate_distance(nodes[i], nodes[i+1]))
    
    return G
```

#### 步骤2：GPS点匹配到路网节点
```python
def match_gps_to_road_nodes(gps_points, road_graph):
    """将GPS点匹配到最近的路网节点"""
    matched_points = []
    
    for point in gps_points:
        # 找到最近的路网节点
        nearest_node = find_nearest_node(point, road_graph)
        matched_points.append({
            'original_point': point,
            'matched_node': nearest_node,
            'distance': calculate_distance(point, nearest_node)
        })
    
    return matched_points
```

#### 步骤3：计算路径并连接
```python
def connect_trajectory_points(matched_points, road_graph):
    """沿路网连接轨迹点"""
    trajectory_lines = []
    
    for i in range(len(matched_points) - 1):
        start_node = matched_points[i]['matched_node']
        end_node = matched_points[i+1]['matched_node']
        
        # 计算最短路径
        try:
            path = nx.shortest_path(road_graph, start_node, end_node, weight='weight')
            # 将路径转换为坐标序列
            path_coords = [road_graph.nodes[node]['coords'] for node in path]
            trajectory_lines.append(path_coords)
        except nx.NetworkXNoPath:
            # 如果无路径，使用直线连接
            trajectory_lines.append([start_node, end_node])
    
    return trajectory_lines
```

### 5.3 性能优化
- **路网缓存**：将路网图缓存在内存中，避免重复构建
- **空间索引**：使用R-tree索引加速最近节点查找
- **路径缓存**：缓存常用路径，避免重复计算
- **批量处理**：批量处理轨迹点，减少数据库查询次数

## 七、优化与风险
- **路网图构建**：大型路网图构建耗时，采用增量更新和缓存策略
- **路径计算**：最短路径算法复杂度高，使用A*算法优化
- **内存占用**：路网图占用内存较大，考虑分区域加载
- **实时性**：路径计算可能影响响应速度，采用异步计算和缓存
