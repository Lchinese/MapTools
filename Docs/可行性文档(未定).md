## 一、系统概述

本系统旨在实现将 GPS 轨迹点序列智能匹配到道路网络上的功能，支持可视化展示与多算法融合。系统采用轻量级架构，兼顾当前快速验证需求与未来扩展能力。

### 核心功能
- ✅ 支持上传多种格式轨迹文件（`.gpx` / `.csv` / `.txt`）
- ✅ 支持出租车GPS数据格式（日期,时间,类型,车牌号,经度,纬度,速度,方向,状态）
- ✅ 支持公交刷卡数据、地铁刷卡数据、出租车交易数据
- ✅ 基于天地图道路数据（Shapefile）进行路径匹配
- ✅ 集成天地图API服务，支持两种投影方式
- ✅ 使用 MySQL 存储与空间计算
- ✅ 集成 GoTrackIt 库实现基于改进隐马尔可夫模型（HMM）的地图匹配
- ✅ 支持多种匹配算法：最近邻匹配（Greedy）和 HMM 算法
- ✅ Web UI 展示原始轨迹与匹配结果
- ✅ 异步任务处理（通过 Redis + Celery）
- ✅ 使用 `uv` 管理 Python 依赖（现代替代 pip）
- ✅ 完整的日志记录系统

| 模块 | 技术 | 选型理由 |
|------|------|----------|
| **前端** | React + Mapbox GL JS | 成熟的地图可视化方案，支持 GeoJSON 渲染 |

## 四、模块化架构设计

### 4.1 设计原则

本系统采用模块化设计，遵循以下核心原则：

- **单一职责原则**：每个模块只负责一个特定功能
- **开闭原则**：对扩展开放，对修改封闭
- **依赖倒置原则**：高层模块不依赖低层模块，都依赖于抽象
- **接口隔离原则**：使用多个专门的接口，而不是单一的总接口
- **松耦合高内聚**：模块间依赖最小化，模块内部功能高度相关

```bash
curl --proto '=https' --tlsv1.2 -sSf https://install.python-poetry.org | python3 -
```

### 2. 创建项目结构

```bash
mkdir MapTools && cd MapTools
```

### 3. 初始化 Docker 环境（`docker-compose.yml`）

```yaml
version: '3.8'
services:
  db:
    image: mysql:8.0
    environment:
      MYSQL_DATABASE: gisdb
      MYSQL_USER: gisuser

      - db

  worker:
    build: ./BackendService
    command: celery -A AsyncTasks.celery_app worker -l info
    depends_on:
      - db
      - redis
    volumes:
      - ./UserUploads:/app/uploads

volumes:
  mysql_data:
  redis_data:
```

```python
def detect_data_format(file_content):
    """自动检测数据格式"""
    lines = file_content.strip().split('\n')
    first_line = lines[0]
    
    # 出租车GPS数据：10个逗号分隔字段
    if ',' in first_line and len(first_line.split(',')) == 10:
        return 'taxi_gps'
    # 公交刷卡数据：空格分隔，包含ISO时间格式
    elif ' ' in first_line and 'T' in first_line:
        return 'bus_card'
    # 地铁刷卡数据：逗号分隔，包含21或22交易类型
    elif ',' in first_line and ('21' in first_line or '22' in first_line):
        return 'metro_card'
    # 公交GPS运行数据：多个逗号分隔字段，包含线路信息
    elif ',' in first_line and len(first_line.split(',')) > 15:
        return 'bus_gps'
    # 出租车交易数据：多个逗号分隔字段，包含时间范围
    elif ',' in first_line and len(first_line.split(',')) == 11:
        return 'taxi_transaction'
    # GPX格式
    elif first_line.startswith('<?xml'):
        return 'gpx'
    # 其他CSV格式
    else:
        return 'csv'
```

## 十、GoTrackIt 库集成方案

### 10.1 GoTrackIt 库简介

GoTrackIt 是一个基于改进隐马尔可夫模型（HMM）的全流程地图匹配 Python 库，专门用于将车辆的 GPS 轨迹数据匹配到道路路网，获取标准化的时空轨迹。

### 10.2 核心功能模块

| 模块 | 功能描述 |
|------|----------|
| **路网生产与优化** | 处理道路网络数据，优化路网结构 |
| **轨迹生产** | 生成和处理 GPS 轨迹数据 |
| **轨迹处理** | 轨迹数据清洗、预处理和特征提取 |
| **地图匹配** | 基于 HMM 的智能轨迹匹配算法 |
| **时空可视化** | 轨迹和匹配结果的可视化展示 |

### 10.3 集成优势

- **专业算法**：基于隐马尔可夫模型的概率图建模，匹配精度高
- **全流程支持**：从轨迹预处理到最终匹配的完整解决方案
- **易于集成**：Python 原生库，与 FastAPI 无缝集成
- **可扩展性**：支持自定义参数和算法调优
- **生产就绪**：经过验证的工业级算法库

### 10.4 使用示例

```python
from gotrackit import MapMatcher, RoadNetwork, Trajectory

# 初始化地图匹配器
matcher = MapMatcher()

# 加载道路网络
road_network = RoadNetwork.from_shapefile("ExternalData/roads.shp")

# 加载轨迹数据
trajectory = Trajectory.from_gpx("UserUploads/track.gpx")

# 执行地图匹配
matched_trajectory = matcher.match(trajectory, road_network)

# 获取匹配结果
result_geojson = matched_trajectory.to_geojson()
```

- **数据流**：轨迹文件 → GoTrackIt 处理 → MySQL 存储 → 前端展示
- **异步处理**：通过 Celery 异步调用 GoTrackIt 算法
- **结果存储**：匹配结果存储到 MySQL 空间数据库
